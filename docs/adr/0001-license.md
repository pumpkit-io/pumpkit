Pumpkit is open source with a paid hosted version. We chose the GNU Affero General Public License v3.0 because it keeps the open-source-plus-paid-cloud model viable (the Postiz model): anyone who hosts a modified version of Pumpkit for others must publish their changes, so a competitor can't run a closed fork of our own product. The alternatives were MIT (maximum adoption, but allows closed hosted forks) and Apache-2.0 (like MIT plus an explicit patent grant). Relicensing later needs agreement from every contributor (or a CLA), so this is hard to reverse.
